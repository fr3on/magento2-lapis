# Security Policy

## Supported Versions

Only the latest release of `magento2-lapis` is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within LAPIS, please send an e-mail to Ahmed via ahmed@0x200.com. All security vulnerabilities will be promptly addressed.

Please include:
- A descriptive title.
- Impact description.
- Steps to reproduce.

Do not use the GitHub issue tracker for security reports.
